# Bridgaem

An infinite physics minigame written in C# using the [Foster](https://github.com/FosterFramework/Foster) library. 

## Compilation

Requirement: dotnet 10.0

In the project's root directory, run the following command to produce a Release build. The executable should then appear in `./bin/Release/net10.0/` (may differ with different dotnet versions).
```sh
dotnet build --configuration Release
```
